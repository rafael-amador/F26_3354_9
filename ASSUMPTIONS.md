A-39 | (stage 2) TD-1 details: how the authenticator app is opened, what "larger screen" means, how a device is remembered | "Add to authenticator app" opens the standard `otpauth://totp/CometFit:<username>?secret=…&issuer=CometFit` link (account filled in); if nothing opens, the app says to use "Copy setup key". The setup key stays visible as selectable text. QR shown when the window is at least 768 px/dp wide. "Remember this device for 30 days" is a checkbox next to the code field. When checked and the code is valid, the server issues a random 256-bit device token, stores only its SHA-256 hash with a 30-day expiry, and the client keeps the token per username (browser localStorage, phone secure store). A remembered sign-in still needs the password, does not extend the 30 days, and only works for the same user. Changing the password forgets all remembered devices. A login with neither code nor device token is rejected as a malformed request (400) before the password is checked; every credential failure still gets one generic 401 message (A-31). | TD-1; D1 NFR Security; A-3, A-6, A-31
