# CometFit

- Team Number: 9
- Team Name: Team 9

`src/` currently contains the source code for checking the logging water intake functionality.

The tech stack is as follows:
- Java for logging functionality
- MySQL for database operations
- Docker for containerized instances
- JUnit for unit testing

To run the program, navigate to `src/` and run `run.sh`. This will automatically bring the docker container up, compile and run the java tests, and tear down the docker container.
