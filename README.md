# CometFit

- Team Number: 9
- Team Name: Team 9

`test/` contains the source code for checking the logging water intake functionality.

The tech stack is as follows:
- Java for logging functionality
- MySQL for database operations
- Docker for containerized instances
- JUnit for unit testing

To run the program, navigate to `test/` and run `run.sh`. This will automatically bring the docker container up, compile and run the java tests, and tear down the docker container.
`app/` contains the CometFit prototype app (Spring Boot server, Expo client), built by an AI using only our project documents. See `app/README.md` to run it and `app/proof/` for the full build log.
